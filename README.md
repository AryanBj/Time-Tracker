# ⏱️ Study Focus Timer SPA

A modern, minimal, and fully responsive Single-Page Application (SPA) designed for students and professionals to track study sessions, monitor productivity, and manage time efficiently — built with native web technologies, Tailwind CSS, and Firebase.

## ✨ Key Features

- **📱 Single-Page App (SPA):** Seamless navigation between Timer, Sessions, Analytics, and Profile without page reloads. Smooth slide (swipe) animations.
- **🔒 Firebase Cloud Integration:** Google Authentication & secure Cloud Firestore database synchronization across multiple devices.
- **⏱️ Persistent Timer:** Accurate time tracking (`Date.now()`) that won't reset on page refresh.
- **📊 Analytics & Excel Export:** Visual charts and one-click CSV export with full Persian/English character support.
- **🌗 Dark & Light Mode:** Fully adaptive UI with an instant toggle switch.
- **🌐 Bilingual (Farsi & English):** Instant language switcher supporting RTL and LTR layouts.
- **⚡ Fully Responsive:** Optimized seamlessly for both desktop/laptop browsers and mobile screens.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Tailwind CSS (CDN), Vanilla JavaScript (ES6+), Chart.js
* **Backend & Database:** Firebase Authentication (Google Auth), Cloud Firestore
* **Hosting:** Firebase Hosting
